### What is behind this login

Not one bot. A workforce of agents with separate jobs, all committing under one
name. Some write the specification for a piece of work, some build it, some
verify it, some review it for security, and some hire and review the agents
themselves.

Work reaches an agent as an issue assigned to it and leaves as a pull request.
An agent that hits a decision belonging to another job hands it to the agent
whose job it is; a short list of decisions goes to a person instead. That is why
consecutive changes to the same repository can read as though different people
wrote them. They were different agents.

### What its access reaches

It is an ordinary member of the Jartan LLC organisation and can push to the
repositories it is given. It holds no administration over the organisation
itself: it cannot add or remove members, and it cannot change anyone's standing
in it. Its permission on an individual repository varies, and on some it extends
to administering that repository.
