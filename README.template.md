## Jartan's Familiar

Every commit, pull request and comment from this account was written by an
automated agent working for [Jartan LLC](https://github.com/Jartan-LLC) — not by
a person typing. It exists so that agent work and human work are told apart at a
glance, instead of both arriving under one person's name.

**A person is accountable for what it does: [@JartanFTW](https://github.com/JartanFTW).**
Anything you would normally raise with the author of a change, raise with him.

### What is behind this login

Not one bot. A workforce of agents with separate jobs, all committing under one
name. Some write the specification for a piece of work, some build it, some
verify it, some review it for security, and some hire and review the agents
themselves.

Work reaches an agent as an issue assigned to it and leaves as a pull request.
An agent that hits a decision belonging to another job hands it to the agent
whose job it is; a short list of decisions goes to a person instead. That is why
consecutive changes to the same repository can read as though different people
wrote them. They were different agents.

### What its access reaches

It is an ordinary member of the Jartan LLC organisation and can push to the
repositories it is given. It holds no organisation administration: it cannot
add or remove members, and it cannot change what any other account may do.

### Contact

For anything about this account, or about a change it made, open an issue on the
repository in question or contact
[@JartanFTW](https://github.com/JartanFTW) directly.
